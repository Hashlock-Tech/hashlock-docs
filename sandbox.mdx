The sandbox runs the same code as production, on testnets. Every production release is deployed to the sandbox right after production, so the API and the MCP tools are the same. Its coins are test coins with no value.

Production stays the default in these docs and the SDK. The local MCP server has no default: you name the API in `HASHLOCK_API_URL`. To use the sandbox, point your client at it.

## Hosts

| | Production | Sandbox |
|---|---|---|
| Site | `https://hashlock.markets` | `https://sandbox.hashlock.markets` |
| REST API | `https://api.hashlock.markets/v1` | `https://api-sandbox.hashlock.markets/v1` |
| Interactive API reference | `https://api.hashlock.markets/v1/docs` | `https://api-sandbox.hashlock.markets/v1/docs` |
| Maker feed | `wss://api.hashlock.markets/v1/ws` | `wss://api-sandbox.hashlock.markets/v1/ws` |
| Hosted MCP | `https://hashlock.markets/mcp` | `https://sandbox.hashlock.markets/mcp` |
| Local MCP `HASHLOCK_API_URL` | `https://hashlock.markets/api` | `https://sandbox.hashlock.markets/api` |

Base and Robinhood Chain have their own chain keys on the sandbox, so an MCP asset reads `USDC@base-sepolia`, not `USDC@base`. The other chains keep their production keys.

## Accounts and API keys

The sandbox has its own accounts and API keys. A production key does not work on the sandbox, and a sandbox key does not work on production. A sandbox key you create starts with `hk_test_`. A key that an MCP client gets through OAuth starts with `hk_oa_test_`.

Create a sandbox key in one of two ways:

- Sign in at [sandbox.hashlock.markets/developers](https://sandbox.hashlock.markets/developers) and create it there.
- Mint it with a wallet signature, as in [API keys](/guides/api-keys), against `https://api-sandbox.hashlock.markets`.

The hosted MCP on the sandbox signs you in with OAuth, as on production, and gives the client a sandbox key (`hk_oa_test_`).

## Point your client at the sandbox

REST: use the base URL `https://api-sandbox.hashlock.markets/v1`.

SDK: pass the sandbox base URL as `baseUrl` (TypeScript) or `base_url` (Python). Give the maker feed the same value.

```typescript
const client = new HashlockClient({ apiKey, baseUrl: 'https://api-sandbox.hashlock.markets/v1' });
```

Hosted MCP: add `https://sandbox.hashlock.markets/mcp` to your client.

Local MCP: set `HASHLOCK_API_URL` to the sandbox and give every chain you settle on a testnet node. The default nodes are mainnet nodes. With a mainnet node, a sandbox settlement fails. Give the sandbox its own `HASHLOCK_SECRETS_PATH`, an absolute path (`~` is not expanded), so its deal secrets stay out of production's `~/.hashlock/mcp-secrets.json`.

```json
{
  "mcpServers": {
    "hashlock-sandbox": {
      "command": "npx",
      "args": ["-y", "@hashlock-tech/mcp"],
      "env": {
        "HASHLOCK_API_URL": "https://sandbox.hashlock.markets/api",
        "HASHLOCK_EVM_KEY": "0x<a key you use on testnets only>",
        "HASHLOCK_EVM_RPC": "https://ethereum-sepolia-rpc.publicnode.com",
        "HASHLOCK_EVM_RPC_BASE_SEPOLIA": "https://sepolia.base.org",
        "HASHLOCK_EVM_RPC_ROBINHOOD_TESTNET": "https://rpc.testnet.chain.robinhood.com",
        "HASHLOCK_TRON_HOST": "https://nile.trongrid.io",
        "HASHLOCK_SOLANA_RPC": "https://api.devnet.solana.com",
        "HASHLOCK_SECRETS_PATH": "/home/<you>/.hashlock/sandbox-secrets.json"
      }
    }
  }
}
```

A Bitcoin key (`HASHLOCK_BTC_KEY`) for the sandbox is a testnet WIF. The other variables are in [MCP server](/agents/mcp).

## Test coins

Hashlock has no faucet. Get each network's coin from a public faucet:

| Network | Coin | Where to get it |
|---|---|---|
| Ethereum Sepolia | ETH | A faucet from [ethereum.org's list of Sepolia faucets](https://ethereum.org/developers/docs/networks/). |
| Base Sepolia | ETH | Bridge Sepolia ETH. Send it from a wallet to Base's `L1StandardBridge` on Sepolia, `0xfd0Bf71F60660E2f608ed56e1659C450eB113120` (listed in [Base's contracts](https://docs.base.org/base-chain/network-information/base-contracts)). It arrives at the same address on Base Sepolia. Base also lists [faucets](https://docs.base.org/get-started/get-funds). |
| Robinhood Chain testnet | ETH | The [Robinhood Chain testnet faucet](https://faucet.testnet.chain.robinhood.com). |
| TRON Nile | TRX | The [Nile faucet](https://nileex.io/join/getJoinPage). |
| Solana devnet | SOL | The [Solana faucet](https://faucet.solana.com). |
| Bitcoin signet | BTC | A public signet faucet. These change often, so none is linked here. |

`GET /v1/assets` on the sandbox lists the tokens it trades. Three of them are the sandbox's own test tokens: USDT on Sepolia, and mUSD on Base Sepolia and on Robinhood Chain testnet. Anyone can mint them: call `mint(to, amount)` on the address that `GET /v1/assets` lists. [Circle's faucet](https://faucet.circle.com) gives test USDC on Sepolia, Base Sepolia and Solana devnet. Get the other tokens from public faucets where they exist.

## What differs from production

- The coins are test coins. Nothing on the sandbox has value.
- Accounts, API keys and webhooks are separate from production's.
- There is no Telegram bot.
- A production release reaches the sandbox right after production. Between releases, the sandbox runs the last one.
